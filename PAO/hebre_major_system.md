## מערכת א׳ — פונטית (Phonetic)

מיפוי לפי צלילים עבריים ייחודיים:

| ספרה | אותיות עבריות |
|------|---------------|
| 0 | ס / ז |
| 1 | ל |
| 2 | ב / נ |
| 3 | ג, ק, כ (כשהיא נשמעת כמו ק במילה) |
| 4 | ד / ת / ט |
| 5 | ח, כ (כשהיא נשמעת כמו ח במילה), ה |
| 6 | ש |
| 7 | ר |
| 8 | מ |
| 9 | פ |

הרחבות שהוספו:
- ז = 0 (כמו S/Z באנגלית — ז היא התאום הקולי של ס)
- נ = 2 (לצד ב — פותח שמות עם צליל N)
- ת / ט = 4 (לצד ד — T ו-D זוג טבעי, כמו באנגלית)
- ה = 5 (לצד ח/כ — אותה משפחת נשיפה, ה שכיחה הרבה יותר)

## מערכת ב׳ — ישירה (Direct)

מיפוי ישיר מול מערכת האנגלית הסטנדרטית — אותו צליל, אות שונה:

| Digit | Standard English sounds | Hebrew equivalent sounds       | Hebrew letters     |
| ----- | ----------------------- | ------------------------------ | ------------------ |
| **0** | s, z                    | ס / ז / צ as "ts"              | ס, ז, צ            |
| **1** | t, d                    | ת / ט / ד                      | ת, ט, ד            |
| **2** | n                       | נ                              | נ, ן               |
| **3** | m                       | מ                              | מ, ם               |
| **4** | r                       | ר                              | ר                  |
| **5** | l                       | ל                              | ל                  |
| **6** | sh, ch, j               | ש / צ׳ / ג׳ / ז׳               | ש, צ׳, ג׳, ז׳      |
| **7** | k, hard g               | ק / כּ / ג hard                | ק, כ/ך when "k", ג |
| **8** | f, v                    | פ/ף as "f", ו as "v", ב as "v" | פ רפה, ף, ו, ב רפה |
| **9** | p, b                    | פּ / בּ                        | פ דגושה, ב דגושה   |

הבדל מרכזי ממערכת א׳: ד/ת/ט=1, נ=2, מ=3, ר=4, ל=5 — במקום ל=1, ב/נ=2, ג/ק/כ=3, ד/ת/ט=4 וכו׳.
