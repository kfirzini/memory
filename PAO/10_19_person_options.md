# 10–19 Person Options — Two Systems

## Encoding Keys

| Digit | Major EN | Major HE-A (Phonetic) | Major HE-B (Direct) |
|-------|----------|-----------------------|---------------------|
| 0 | S / Z | ס / ז | ס / ז / צ |
| 1 | T / D | ל | ת / ט / ד |
| 2 | N | ב / נ | נ |
| 3 | M | ג / ק / כ (hard) | מ |
| 4 | R | ד / ת / ט | ר |
| 5 | L | ח / כ (soft) / ה | ל |
| 6 | J / SH / CH | ש | ש / צ׳ / ג׳ / ז׳ |
| 7 | K / hard-G | ר | ק / כּ / ג-hard |
| 8 | F / V | מ | פ-רפה / ו / ב-רפה |
| 9 | P / B | פ | פ-דגושה / ב-דגושה |

**Major EN** = first two major consonant sounds of the name  
**Major HE** = same rule, using the Hebrew phonetic map above

For 10–19: first consonant is T/D (EN) | ל (HE-A) | ת/ט/ד (HE-B).  
Note: ת/ט/ד = 1 in HE-B but = 4 in HE-A — names in HE-B sections here fall in HE-A slots **40–49**.
